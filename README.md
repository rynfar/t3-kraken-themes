# T3 Kraken Themes

Custom T3 Code themes inspired by Kraken's Kinetic design language and Apple Liquid Glass.

## Themes

- **`themes/kraken-glass.json`** (`Kraken Glass`): Dark-first (with full Light variant) Apple Liquid Glass theme featuring a floating obsidian sidebar with subtle animated Peek Flow rainbow borders, unified `#0A0B0E` backdrop, smoked selected thread rows, cohesive translucent switches/inputs/selects/popups/tooltips, and embedded **Figtree** + **Geist Mono** typography.
- **`themes/kraken-kinetic.json`** (`Kraken Kinetic`): Light/dark Kraken Kinetic palette port with the Peek Flow spectral composer focus halo.

## Backups

- **`backups/kraken-glass-v9.json`**: Snapshot of `Kraken Glass` prior to the full v10 control/consistency pass.

## Usage

Install themes into T3 Code (`~/.t3/userdata/themes`):

```bash
./install.sh
```

Pull future edits made in `~/.t3/userdata/themes` back into this repo before committing:

```bash
./sync.sh
```
